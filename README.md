# ⚡ QuizMaster Pro

An interactive, modern, glassmorphic Quiz Application built with HTML5, CSS3, and JavaScript, with built-in procedural Web Audio synthesis, physics confetti, customizable categories, and full offline support.

---

## ✨ Features

- 🎨 **Modern Aesthetics**: Sleek dark mode obsidian theme with glowing neon gradients (electric cyan, vibrant violet, and emerald) and smooth micro-animations.
- 🐍 **Diverse Question Bank**:
  - **Python & Coding**: Pythonic tricks, generator mechanics, list comprehensions, OOP, and syntax challenges.
  - **Web & Modern Tech**: JavaScript event loop, CSS box models, Git workflows, HTTP/3, and computer history.
  - **Science & Cosmos**: Quantum entanglement, black hole physics, cosmology, and genetics.
  - **General Knowledge & Trivia**: Historical milestones, geography, discoveries, and world facts.
- 🎮 **4 Game Modes**:
  - **Classic Timed**: 15 seconds per question with bonus speed points.
  - **Blitz Rush**: 8-second intense rapid-fire with 1.5x score multiplier.
  - **Survival**: 3 Hearts/Lives; sudden death when lives reach 0!
  - **Zen Practice**: No timer; explore questions and read explanations at your own pace.
- 🛟 **Lifelines**:
  - **50:50**: Eliminates two wrong answers.
  - **Freeze / +15s**: Adds extra time to the countdown clock.
  - **Skip**: Skip directly to the next question without score deduction.
- 🔥 **Streak Multipliers & Confetti**:
  - Chain consecutive correct answers for 1.2x, 1.5x, and 2.0x combo bonuses with sound cues and canvas confetti celebrations!
- 🔊 **Zero-Asset Procedural Audio (Web Audio API)**:
  - Ascending melodic chimes for correct answers, soft harmonic buzzes for wrong answers, urgency ticks for countdowns, and victory fanfares.
  - Toggle mute on/off at any time.
- ✏️ **Custom Quiz Creator & Importer**:
  - Build your own quizzes with custom titles, emojis, code snippets, and explanations.
  - Export your quizzes to `.json` files.
  - Import external quiz JSON files into your local library.
- 📊 **Detailed Run Review & Performance Stats**:
  - Circular animated accuracy gauge.
  - Question-by-question review showing your choice vs the correct answer and detailed educational explanations.
  - Shareable score card copied directly to your clipboard.
- ⌨️ **Keyboard Navigation**:
  - Press `1`, `2`, `3`, `4` or `A`, `B`, `C`, `D` to select options.
  - Press `Enter` or `Space` to advance to the next question.

---

## 🚀 How to Run

### Option 1: Using Python Server (Recommended)
From your terminal in this directory:
```bash
python server.py
```
This starts a lightweight server at `http://localhost:8000` and automatically opens it in your default browser.

### Option 2: Direct Browser Launch
Simply double-click `index.html` or open it directly in any modern browser (Chrome, Edge, Firefox, Safari).
No installation, build step, or npm packages required!
